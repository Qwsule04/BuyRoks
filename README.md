# BuyRoks

A univercity project for a WEB Technologies 1 (Front End) class.

Topic: Pet rocks shop 

Goal: a responsive multi-page website built with HTML and CSS only. Group: MT-2505, Team 27

Group: MT-2505

Team members: Mukashev Aidos, Nurbek Myktybek, Sakat Kabdrash.

Site consists of:
- index.html (by Mukashev Aidos)
- reviews.html (by Sakat Kabdrash)
- about.html (by Nurbek Myktybek)

Githun pages URL: https://qwsule04.github.io/BuyRoks/

How to open locally

Download or unzip the project and open index.html in a browser.

Limitations

The site is static. The forms only check the fields with native HTML validation and open a demo page, no data is sent or stored.
